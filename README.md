# 용용이네 & 밧디글라 주문 폼

```
index.html (고객 주문, 모바일 웹)  →  Apps Script doPost  →  구글 시트 "주문"
                                            ├─ 담당자 문자 (즉시, 문자 키 없으면 메일로)
                                            ├─ 매일 06:00 요약 문자 (주문 없으면 생략)
                                            ├─ 매일 21:00 오늘 주문 엑셀 메일 (주문 없으면 생략)
                                            └─ 시트 '입금확인' 체크 → 고객 문자
```

> `apps-script/`는 git에 올리지 않습니다 (담당자 번호·메일 포함). 실제 코드는 시트의 Apps Script 편집기에 있는 것이 기준입니다.

## 설치 (10분)

1. 구글 시트 새로 만들기 → 확장 프로그램 → Apps Script
   (반드시 **시트 안에서** 열 것. script.google.com에서 따로 만들면 시트를 못 찾아 주문이 저장되지 않음)
2. `apps-script/Code.gs` 내용을 붙여넣고 저장
3. 편집기에서 `setup` 함수 1회 실행 → **권한 허용** → 시트 탭 + 트리거 생성
4. 편집기에서 `test_doPost` 실행 → 로그에 `ok`, 메일함에 `[문자 테스트]` 메일이 오면 정상
5. 배포 → 새 배포 → 웹 앱 → 실행: **나**, 액세스: **모든 사용자** → 배포 → URL 복사
6. `index.html` 상단 `API_URL`에 붙여넣기, `ACCOUNT`에 계좌 입력
7. `index.html`을 GitHub Pages 등에 올리기 (파일 하나라 어디든 됨)

## ⚠️ Code.gs를 고친 뒤에는 꼭 재배포

웹 앱은 **배포한 시점의 코드**로 계속 돌아갑니다. 편집기에서 저장만 하면 반영되지 않아요.

배포 → **배포 관리** → 연필(수정) → 버전: **새 버전** → 배포

- URL이 그대로라 `index.html`은 안 고쳐도 됨
- "새 배포"를 누르면 URL이 바뀌니 주의 (바꿨다면 `index.html`의 `API_URL`도 교체)
- 코드에 메일·문자 같은 새 기능이 들어가면 편집기에서 아무 함수나 한 번 실행해 **권한 허용**을 다시 해야 함.
  승인 전에는 주문이 와도 스크립트가 바로 멈춰서 시트도 비고 메일도 안 옴

## 문자 켜기 (나중에)

1. solapi.com 가입 → 발신번호 등록 → API 키 발급 → 충전
2. 편집기 → 프로젝트 설정(⚙) → **스크립트 속성**에 `SOLAPI_KEY` / `SOLAPI_SECRET` / `SENDER_PHONE` 추가
3. 세 개가 모두 채워지면 문자 발송이 자동으로 켜짐 (재배포 불필요)
4. 편집기에서 `test_sms` 실행 → 담당자 번호로 테스트 문자 확인

키가 없는 동안에는 `SMS_TO_EMAIL = true` 설정 때문에 문자 내용이 `MANAGER_EMAIL`로 메일 발송됩니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 시트가 비어 있고 메일도 안 옴 | 편집기에서 `test_doPost` 실행 → 권한 허용 → `ok`인지 확인 후 **새 버전 배포** |
| `test_doPost`가 "행 추가 실패" | 같은 번호 1분 내 중복 차단에 걸린 것. 1분 뒤 다시 실행 |
| 폼에서 "주문이 접수되지 않았어요" | 편집기 왼쪽 **실행**(≡▶) 메뉴에서 `doPost` 오류 확인 |
| 주문 메일이 어디로 가는지 | `Code.gs` → `MANAGER_EMAIL` |
| 화면 구석에 `undefined` 같은 글자 | 크롬 확장 프로그램 문제. 시크릿 창에서 안 나오면 무시 |

## 수정할 곳

| 무엇 | 어디 |
|---|---|
| 품목·가격 | `index.html` → `ITEMS` |
| 계좌번호 | `index.html` → `ACCOUNT` |
| 담당자 번호·메일 | `Code.gs` → `MANAGER_PHONE`, `MANAGER_EMAIL` (고친 뒤 새 버전 배포) |
| 문자 문구 | `Code.gs` → `sendSms(...)` 호출부 (고친 뒤 새 버전 배포) |
